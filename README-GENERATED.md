# My movie

This Capacitor project was generated by **Web2App Studio**.

- **Website:** https://site-agentlucife.vercel.app/
- **Application ID:** com.site.myapp
- **Version:** 1.0.0 (1)
- **Platforms:** Android + iOS

The app loads the configured website in a native WebView. The files in `www/` are an offline
fallback and are not a replacement for the website.

## Local development

```bash
npm install
npx cap add android   # if you want to open the native project locally
npx cap add ios
npx @capacitor/assets generate --android --ios
node scripts/apply-native-config.mjs android
node scripts/apply-native-config.mjs ios
npx cap sync
```

## GitHub Actions builds

Two workflows are committed:

- `.github/workflows/android.yml`
- `.github/workflows/ios.yml`

They are dispatched by Web2App Studio. You can also run them manually from the
Actions tab.

### Android release signing

Add these repository secrets (**Settings → Secrets and variables → Actions**):

| Secret | Description |
| --- | --- |
| `ANDROID_KEYSTORE_BASE64` | Base64 of your keystore: `base64 -w 0 release.keystore` |
| `ANDROID_KEYSTORE_PASSWORD` | Keystore password |
| `ANDROID_KEY_ALIAS` | Key alias |
| `ANDROID_KEY_PASSWORD` | Key password |

Generate a keystore with:

```bash
keytool -genkeypair -v -keystore release.keystore -alias release \
  -keyalg RSA -keysize 2048 -validity 10000
```

Never commit a keystore or its passwords. Debug APKs are signed with the Android
debug key and are for testing only.

### iOS signing

iOS builds run on a macOS runner with Xcode. To produce an **installable IPA**
you must add:

| Secret | Description |
| --- | --- |
| `IOS_BUILD_CERTIFICATE_BASE64` | Base64 of a `.p12` distribution certificate |
| `IOS_BUILD_CERTIFICATE_PASSWORD` | Password of the `.p12` |
| `IOS_PROVISIONING_PROFILE_BASE64` | Base64 of a `.mobileprovision` profile |
| `IOS_TEAM_ID` | Apple Developer Team ID |
| `IOS_EXPORT_METHOD` | `app-store`, `ad-hoc`, `development` or `enterprise` |

Without these secrets an iOS build produces an **unsigned .xcarchive**, which is
useful for inspection but **cannot be installed on a device**. You also need an
Apple Developer account for App Store distribution.

### Push notifications

The Push Notifications plugin is installed and permission entries are generated.
Delivery additionally requires a Firebase project (`google-services.json` for
Android) and APNs credentials / entitlements for iOS. Add those in your own
Firebase/Apple accounts. Web2App Studio does not supply push credentials.

### Universal links (https)

Android App Links are generated when a deep-link host is configured. iOS
Universal Links additionally require the Associated Domains capability, an
`apple-app-site-association` file on your domain, and an Apple development team.
Open the iOS project in Xcode and enable the capability before shipping.

## Security

- The website must be reachable over HTTPS for production builds.
- Do not commit signing material or service credentials to this repository.
- Keep dependencies updated with `npm outdated` / `npm audit`.
